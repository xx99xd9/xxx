# Описание конфликта Git

## Где возник конфликт?
Конфликт возник в файле `api-plan.md` при попытке слияния ветки `feature-api` в ветку `main`. 
В обеих ветках параллельно была изменена первая строка с описанием базового API-эндпоинта.

## Как он был решен?
Конфликт был разрешен вручную. Из файла были удалены маркеры конфликта (`<<<<<<`, `======`, `>>>>>>`), 
а эндпоинты были скомбинированы в коммите исправления.
